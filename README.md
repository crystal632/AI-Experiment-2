# 实验二：搜索算法

## 1. 项目说明
本项目完成《当代人工智能实验课：实验二—搜索算法》的四道题目：

- 题目一：迷宫寻路（A*）
- 题目二：加权地形（A*）
- 题目三：极大极小博弈树（Minimax 与 Alpha-Beta）
- 题目四：竞争环境下的宝藏分配（A* + Minimax + Alpha-Beta）

## 2. 文件结构

```text
实验二最终提交材料/
├── astar.py                 # 题目一、题目二
├── minimax.py               # 题目三
├── treasure_game.py         # 题目四（启发式排序最终版）
├── README.md                # 运行说明
```

## 3. 环境要求

- Python 3.10 或更高版本（代码仅使用 Python 标准库）
- 无需安装第三方 Python 包

## 4. 运行方法

在本目录打开终端，依次运行：

```bash
python astar.py
python minimax.py
python treasure_game.py
```

Windows PowerShell 也可以使用：

```powershell
py astar.py
py minimax.py
py treasure_game.py
```

如果使用虚拟环境，请先激活虚拟环境，再执行上述命令。

## 5. 实际测试结果摘要

以下数据来自本次对提交目录中三个 Python 文件的实际运行：

### 题目一
- 最短路径：`[(0,0), (0,1), (0,2), (1,2), (1,3), (1,4), (2,4), (3,4)]`
- 路径长度：7 步
- 曼哈顿启发函数有效出队节点数：14
- `h=0` 有效出队节点数：17

### 题目二
- A* 最小总代价：7
- 修正启发函数有效出队节点数：11
- `h=0` 最小总代价：7
- `h=0` 有效出队节点数：15

### 题目三
- Minimax 最佳得分：5，访问节点数：15
- Alpha-Beta 左到右：得分 5，访问节点数 14，剪枝直接子节点数 1
- Alpha-Beta 右到左：得分 5，访问节点数 14，剪枝直接子节点数 1

### 题目四
- A* 6×6 距离矩阵已在程序中输出。
- H=2：最优首步 T2，最优收益差 -1。
- H=4：最优首步 T3，最优收益差 3。
- H=2：Minimax 17 节点；Alpha-Beta 左/右/启发式分别为 13/16/11 节点。
- H=4：Minimax 65 节点；Alpha-Beta 左/右/启发式分别为 47/46/37 节点。

节点统计口径：
- A* 的 `expanded_nodes`：从优先队列弹出且不是过期记录的节点数，包含最终弹出的目标节点。
- Minimax / Alpha-Beta 的 `visited_nodes`：递归搜索实际访问的节点数。
- Alpha-Beta 的 `pruned_children`：发生剪枝时被直接跳过的子节点数量，不是被跳过子树中的全部节点数量。

## 6. 复现与报告说明

1. 结果在相同 Python 环境中运行三个脚本。
2. 实验报告中的结果表格与本次控制台运行输出一致。
3. `treasure_game.py` 使用启发式排序最终版：A、B 两名玩家均按当前可选宝藏的即时收益从高到低排序，以改善 Alpha-Beta 的剪枝效率；这只影响搜索顺序，不改变 Minimax 最优值。
